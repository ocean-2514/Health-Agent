# 电力设备全寿命周期健康管控智能体助手

本系统旨在通过工业物联网实时采集电力设备数据，利用大小模型协同，进行多维度的健康状况评估，并生成专业的专家建议与生命周期推演报告。

## 核心功能
- **Agent 协作分析**：
  - **缺陷识别 Agent**：根据设备图片、文本和数值特征精准识别设备潜在缺陷。
  - **寿命推演 Agent**：基于历史趋势与损耗模型推算设备剩余寿命。
  - **专家评价 Agent**：汇总 AI 意见并输出可落地的维检修方案。
- **现代化看板**：采用 React + Vite 开发的响应式报表系统，支持健康度分布视图。

## 项目结构
- **`/Python`**: 后端核心逻辑。主入口为 `Main.py`。
- **`/Web`**: 前端 React 应用。
- **`/Config`**: 系统配置文件，支持本地/云端模型切换。

## 快速启动
### 1. 环境准备
- **Python**: 3.10+ (推荐 3.10 - 3.12，以兼容特定的 AI Agent 库，推荐使用虚拟环境 `.venv`)
- **Node.js**: 18+ 或 20+ (配合新版 Vite 与 React，推荐使用 `npm` 或 `yarn`)
- **IoTDB**: 确保 Apache IoTDB 正在运行（本项目测试版本为 1.3.3，默认端口 6667）。

### 2. 后端部署
```bash
# 安装依赖
pip install -r requirements.txt

# 修改配置（见下文“本地化部署”节）
# 启动服务
python Python/Main.py
```

### 3. 前端部署
```bash
cd Web
npm install
npm run dev
```

## 本地化与内网部署
针对工业界特殊安全需求，本系统支持**完全脱网**运行：
1. **模型配置**：修改 `Config/GlobalConfig.yaml`，将 `LLM.Local` 设置为您的内网模型地址（如 Ollama 为 `http://localhost:11434/v1`）。
2. **数据隔离**：确保 IoTDB 在内网环境可访问，由于配置文件已解耦，无需修改任何核心代码即可完成迁移。
