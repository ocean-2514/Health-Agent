# DGA 故障判读指南

油中溶解气体分析(Dissolved Gas Analysis)是判断变压器内部故障类型的核心手段。
当用户给出 H2/CH4/C2H6/C2H4/C2H2 等气体浓度(ppm),或问"这组气体说明什么故障"时,
按下面的步骤判读。

## 1. 关键气体特征

| 主导气体 | 指向的故障 |
|---|---|
| H2 为主 | 局部放电(低能放电) |
| CH4 + H2 | 低温过热(<300°C) |
| C2H4 为主 | 高温过热(>700°C) |
| C2H2 为主 | 高能电弧放电 |
| CO / CO2 升高 | 固体绝缘(纸)老化/过热 |

## 2. IEC 60599 三比值法

计算三个比值,查编码表:

- 比值1 = C2H2 / C2H4
- 比值2 = CH4 / H2
- 比值3 = C2H4 / C2H6

典型判读:
- (0,0,0) → 正常老化
- (0,1,0) → 低温过热 <150°C
- (0,0,1) → 低温过热 150-300°C
- (0,0,2) → 中温过热 300-700°C
- (0,0,>2) → 高温过热 >700°C
- (1,0,0) → 局部放电
- (1,0,1-2) / (2,0,2) → 电弧放电(高能)

## 3. Duval 三角法(交叉验证)

用 CH4、C2H4、C2H2 三者百分比定位三角区:
- PD(局放)、D1(低能放电)、D2(高能放电)
- T1(<300°C)、T2(300-700°C)、T3(>700°C)
- DT(电与热混合故障)

三比值法落在"无编码"区时,优先用 Duval 三角给结论。

## 4. 输出建议

判读后给用户:
1. **故障类型**(过热/放电/电弧,及温度/能量等级)
2. **判读依据**(哪个比值/哪个三角区)
3. **严重程度**与建议复测周期
4. 若 C2H2 显著(>5ppm 且增长)→ 强调电弧风险,建议尽快停电检查

注意:单次绝对值需结合**产气速率**(ppm/天)判断;只有一次快照时,在结论里注明
"建议复测以确认增长趋势"。
